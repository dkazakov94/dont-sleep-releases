Support

Don't Sleep is a menu bar utility for keep-awake sessions, timers and a configurable battery cutoff.

Display sleep allows macOS to turn off the display. Your Mac continues working during an active session; screen locking follows your macOS settings.

Backlight only lowers the built-in display brightness to zero. Mouse or keyboard input restores brightness. This is different from locking the screen.

Changing the display behavior applies to the current session immediately. Use the action button to turn off the display now, or select an inactivity interval.

Trial and purchase

The App Store version will offer a free 7-day trial. After the trial, a one-time purchase unlocks full access. There is no subscription or automatic charge. Use Restore purchases with the same Apple Account to recover access. The optional companion is free and does not extend the trial.

Optional companion

The planned App Store version uses a separate companion for closed-lid sessions and backlight control. The companion requires installation in Applications and approval of its background service in macOS. It is still undergoing installation and recovery checks.

Report problems through GitHub Issues. Include the app version, macOS version and steps to reproduce. Issues are public: do not post passwords, personal documents or unreviewed logs.

Privacy policy

Updated 26 October 2026 · Dmitry Kazakov

The current application and companion process session settings, battery and power status, lid state and display brightness locally on your Mac. They use input activity to detect inactivity and restore the display. They do not record the text you type.

Settings, saved brightness and diagnostic session events are stored locally. The application and companion do not include advertising, analytics or automatic log uploads, and do not require an account.

If you voluntarily submit a support issue, GitHub receives the information you submit. This website and downloads are hosted by GitHub, which may process technical request data such as IP addresses under its privacy statement. This page does not add analytics or tracking cookies.

Purchases and App Store downloads, when available, are processed by Apple under Apple's privacy policy. Contact the developer about privacy through GitHub Issues without including sensitive information.

Поддержка

Don't Sleep работает из строки меню: не даёт Mac уснуть во время сессии, поддерживает таймер и отключение при выбранном заряде батареи.

Сон дисплея разрешает macOS отключить экран. Во время сессии Mac продолжает работу, блокировка зависит от настроек macOS.

Только подсветка снижает яркость встроенного экрана до нуля. Мышь или клавиша возвращает яркость. Это отдельное действие, не блокировка экрана.

Переключение способа гашения применяется сразу к текущей сессии. Чтобы погасить экран сейчас, нажми кнопку под настройкой, либо выбери время бездействия.

Политика конфиденциальности

Обновлено 26 октября 2026 · Дмитрий Казаков

Текущая версия приложения и дополнительный компонент обрабатывают настройки сессии, заряд батареи, питание, положение крышки и яркость локально на Mac. Активность мыши и клавиатуры используется для определения бездействия и восстановления экрана. Вводимый текст не записывается.

Настройки, сохранённая яркость и события сессии хранятся локально. В приложении и компоненте нет рекламы, аналитики и автоматической отправки журналов. Аккаунт для работы не нужен.

Если ты сам отправляешь обращение, GitHub получает указанные в нём сведения. Сайт и скачивания размещены на GitHub, который может обрабатывать технические данные запросов, включая IP-адрес, по своей политике конфиденциальности. На этой странице нет дополнительной аналитики и отслеживающих cookies.

Когда приложение появится в App Store, покупки и загрузки будет обрабатывать Apple по своей политике конфиденциальности. Вопросы разработчику о конфиденциальности можно оставить в GitHub Issues, не добавляя чувствительные данные.
