# Don't Sleep Companion

Installers and release notes for the optional Don't Sleep companion for macOS. Application source code is not included in this repository.

The companion is being developed to add closed-lid sessions and built-in display backlight control to Don't Sleep.

## Downloads

No public release is available yet. Installation and recovery checks are still in progress.

Verified installers will appear in [Releases](https://github.com/dkazakov94/dont-sleep-releases/releases) with version information and SHA-256 checksums.
